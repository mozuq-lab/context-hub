# 選んで深掘り（Claude Code用）

手順の正本はVaultの `_ContextHub/docs/guided-capture.md` です。最初に読み、その手順に従ってください。読めない場合は、手順書が配置されていないことを本人に伝えて止めます。Vault直下のAGENTS.mdの読む範囲・方針・保存の決まりも守ります。

引数: $ARGUMENTS

引数に目的・プロジェクト・一言があれば使います。目的がなければ、最初の問いで記録・壁打ち・アイデアから選んでもらいます。

## AskUserQuestionでの聞き方

- 1回の呼び出しで聞くのは1問だけ。次の問いは、本人の答えを見てから作る。
- `header` は12文字以内で、目的と問番号を書く（例: `記録 3/10`）。
- 選択肢は2〜4個。「その他」はツールが付けるので選択肢に入れない。3問目以降は、4個目を「ここでまとめる」にしてよい。
- 各選択肢の `description` には、選ぶと何を意味するかを短く書く。
- 複数当てはまるのが自然な問いだけ `multiSelect: true` にする。
- 聞く前に、ここまでの理解を1〜3文で本文に書く。
- 最初の問いの前に一度だけ「選択肢から選ぶか、『その他』に一言書いてください。『わからない』『戻る』『まとめる』も『その他』に書けば使えます」と伝える。

「その他」に書かれた内容は、次のように扱います。

| 書かれた内容 | 扱い |
|---|---|
| 「わからない」など | 答えずに次へ進む。問答の記録には「わからない」と書く |
| 「戻る」「2問目から」など | その問いから選び直す。以降の回答は捨てる |
| 「まとめて」「ここまで」など | まとめへ進む |
| それ以外 | 本人の言葉として、そのまま「自由入力」で記録する |

## まとめと保存

- まとめは手順書の書式で書き、本文全体を本人に示して確認してもらう。
- 本人が保存を指示してから、`submit-input.mjs` に `--kind memo --tool claude-code` を付けて保存する。`--source` と結果の扱いは手順書と `file-input.md` に従う。`work-summary` にはしない。
- 保存しないと言われたら、何も書かずに終える。
